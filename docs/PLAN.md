## 0. 한 줄 요약

**3개 원룸에서 수집한 ESP32-C6 CSI 데이터로 낙상(fall) vs 비낙상(일상+부재) 이진 분류기를 학습하되,
"4번째 미지의 집 + 미지의 사람"에게 그대로 배포 가능하도록 — 새 집에서는 부재(빈 방) 데이터
10~30분만 수집해 캘리브레이션 — 하는 전처리/정규화/모델 조합을 실험으로 찾아낸다.**

## 1. 목표와 배포 시나리오

### 배포 시나리오 (이 프로젝트의 모든 설계가 이것을 따른다)
1. 4번째 집(미지의 집, 미지의 거주자)에 TX 1대 + RX 4대를 **기존 3집과 같은 상대 배치**로 설치.
   - 배치 규약: 방을 위에서 볼 때 TX가 6시 방향, RX1→RX2→RX3→RX4가 **반시계 방향** 순서
     (예: RX1 4시, RX2 1시, …). TX 양옆에 RX1·RX4가 오도록 3집 모두 최대한 동일하게 맞췄음.
2. 설치 직후 **부재(집에 아무도 없음) 데이터 10~30분** 수집. 이것이 그 집에서 얻을 수 있는 **유일한** 적응 데이터.
3. 이후 실시간 스트림(33 Hz)이 들어오면 부재 데이터 기반 캘리브레이션을 거쳐 **즉시 낙상/비낙상 추론**.
4. 새 집에서 낙상·일상행동 데이터 수집은 **불가능** (fine-tuning 금지).

### 성공 기준
- 미지의 집(+미지의 인물)에 대한 **균형 지표(F1/ROC-AUC/PR-AUC) 중심** 평가에서 강인한 성능.
- 임계값별 트레이드오프 곡선(낙상 recall vs 오경보율) 제공.
- 지연(latency)은 무관 — 낙상 후 5초 뒤 감지도 허용. 정확도 우선.

## 2. 데이터 요약 (README/manifest/meta + 사용자 확인으로 확정된 사실)

### 구성
- 위치: `csi-home-dataset-v1.0/` (**원본 아님 — 복사본. 그래도 읽기 전용으로 취급, 절대 수정 금지**)
- 3집 × 4인 × 4행동 × 120초 = 48세션 + 집당 부재(empty) 1920초 × 3 = **51세션, 4.9 GB, 결측 0**
- 집: `home_A`(v1, 2026-07-30), `home_B`·`home_C`(v2, 2026-08-04~05)
- 인물: `P1`, `P2`, `P3`, `P4` — **4명 전원이 3집 모두에 등장** (집과 인물이 교차됨)
- 행동: `walk`, `sitdown`, `liedown`, `handsup` / 부재: `none/empty`

### 행동의 실제 내용 (사용자 확인)
| 행동 | 내용 | 클래스 |
|---|---|---|
| `liedown` | 침대 위에 서 있다가 **확 넘어짐** (주기적 반복) | **낙상** |
| `sitdown` | 침대에 걸터앉아 있다가 **확 옆으로 넘어짐** (반복) | **낙상** |
| `handsup` | 제자리에 서서 양팔만 움직임 | 일상 |
| `walk` | 집안을 걸어다님 | 일상 |
| `empty` | 완전 부재 (사람·동물·가동 가전 없음) | 일상(비낙상) |

- 낙상 세션 내부 사이클: **일정한 주기는 없으나** 대체로 "가만히 서/앉아 있음 → 확 넘어짐 →
  ~1.5초 누워 있음 → 다시 일어남"이 **약 5~7초** 간격으로 반복.
- 행동 세션 중 집에는 피험자 1명뿐. empty는 진짜 완전 부재.

### 수집 환경
- 3집 모두 **약 19 m² 원룸** — TX·RX 4대가 전부 한 방 안. 행동도 그 방 안에서 수행.
- ESP32-C6 외장 안테나, ch11 / HE20(802.11ax SU) / MCS0 / 프로브 33 Hz.
- CSI: 256 서브캐리어 × (I,Q) int8. 가드+DC 10개 제외 → **유효 진폭 246차원/노드**, 노드 4개.
- `synced.csv`: seq 격자 정렬(33 Hz), 17컬럼. `rx{N}`=1이면 해당 슬롯 수신, 0이면 결측.

### ⚠ 데이터 품질 지뢰 (README 명시)
1. **두 세대의 품질 트레이드오프가 반대**:
   - `home_A`(v1): 동기화 나쁨(완전행 40~75%, 노드1·4가 특히 결손) / 신호 양호(RSSI −42~−58).
     결측 구조는 좋음 — 98.7%가 3프레임(90 ms) 이하, 최대 연속 7프레임 → 선형 보간으로 복원 가능.
   - `home_B`·`home_C`(v2): 동기화 좋음(94.6~98.4%) / **신호 포화**(RSSI −20~−44).
     특히 `home_C` rx4는 실효 분해능 3~4비트.
2. **절대 진폭 비교 금지**: 세션 평균 |H|가 집·노드에 따라 최대 20배 차이 (AGC 상태 차이).
   정규화 없이 학습하면 모델이 "어느 집인지"를 학습한다. → 이 프로젝트의 핵심 주제와 직결.
3. 노드 번호는 도메인 불변 특징이 아님 — 다만 본 데이터는 **배치 규약으로 상대 기하를 통일**했으므로
   노드 순서를 유지해 사용하되, 노드 서브셋/순열 ablation으로 민감도를 확인한다.
4. 진짜 "낙상" 라벨의 세션은 없음 — liedown/sitdown이 낙상의 프록시(침대 위 안전 낙상).
5. `home_A/P1/walk·handsup`은 240초 수집분을 120초로 트리밍한 세션(데이터 결함 없음).
6. v1 meta의 `framer`/`unknown_rx`/`sync.seq_outlier` 등 null은 "정보 없음"이지 0이 아님.

## 4. 문제 정식화

### 입력 단위 (윈도우)
- 33 Hz seq 격자 위에서 길이 W 패킷(기본 후보 W ∈ {100, 200, 300} ≈ 3/6/9초) 윈도우를
  스트라이드 ~33패킷(1초)으로 슬라이딩.
- 텐서 형태: `(4 노드, W 시간, 246 서브캐리어)` 진폭 (+ 파생 특징 채널).

### 라벨링 규칙 (약한 라벨의 정당화)
- 낙상 사이클이 5~7초이므로 **W ≥ 200패킷(6초) 윈도우는 낙상 세션 내 어디를 잘라도
  낙상 순간 또는 그 직후(누움/일어남)를 포함**한다. → 낙상 세션의 모든 윈도우 = 양성.
- W = 100(3초)에서는 이 보장이 약해짐 → 신호 에너지 기반 이벤트 검출로 라벨 정제를 병행하고,
  정제 유무를 ablation으로 비교.
- 비낙상: walk/handsup/empty 세션의 모든 윈도우 = 음성.

### 평가 지표
- **윈도우 수준**: ROC-AUC, PR-AUC(양성=낙상), F1(최적 임계값), 고정 임계값 규칙 하 F1.
- **운영 수준**: 낙상 세션별 경보 발생률(near event-level recall) + 음성 스트림(walk/handsup/empty
  평가분)에 대한 **시간당 오경보 횟수(FA/h)**. recall–FA/h 트레이드오프 곡선.
- **배포 가능한 임계값 규칙**도 평가: 새 집 부재 캘리브레이션 데이터의 점수 분포에서
  임계값을 자동 설정(예: 부재 점수의 극단 분위수 + 마진) → 라벨 없이 임계값을 정하는 방법 검증.

### 평가 프로토콜 (데이터 누수 방지 규칙 포함)
1. **LOHO (기본)**: 3폴드. 학습 = 2집 전체(각 집의 empty 포함), 테스트 = 남은 1집.
2. **Dual-unseen (강화)**: 3집 × 4인 = 12조합. 각 조합에서 학습 = 나머지 2집 × 나머지 3인(+2집 empty),
   테스트 = 남은 집의 남은 1인 세션 4개 + 그 집 empty 평가분. 12조합 평균±표준편차 보고.
3. **캘리브레이션 규칙**: 테스트 집의 empty 세션(1920초)을 시간순으로 분할 —
   **앞부분 K분 = 캘리브레이션 전용**(정규화 통계·임계값 설정에만 사용),
   **나머지 = 평가용 음성 스트림**. K ∈ {1, 5, 10, 30} ablation. 기본 K=10.
   학습 집들도 각자 자기 empty 앞 K분으로 같은 방식 정규화(배포 상황과 일치시키기 위함).
4. 테스트 집의 행동 데이터는 어떤 형태로도(통계 포함) 학습·튜닝에 사용 금지.
5. 하이퍼파라미터/조기종료는 학습 집들 내부 분할(예: 학습 인물 중 1인 홀드아웃)로만 결정.

## 5. 전처리 파이프라인

### 고정 단계
1. `synced.csv` 파싱 → 노드별 `(T, 246)` 진폭 float32 + 수신 마스크 + RSSI. **npz 캐시** (1회, `cache/`).
2. 결측 슬롯: **진폭 도메인 선형 보간** (기본, 사용자 아이디어이자 실시간 구현 용이).
   비교 대상: 직전값 유지(zero-order hold). 긴 결측(>10프레임) 구간은 플래그.
3. (실험에 따라) 서브캐리어 스무딩/대역 축약, 시간축 저역통과.

### 정규화 후보 — 이 프로젝트의 핵심 실험 변수
| ID | 방법 | 배포 가능? | 근거 |
|---|---|---|---|
| N0 | 없음 (대조군) | — | 실패를 보여주는 기준선 |
| N1 | 세션별 z-score (오라클) | ✗ (실시간 불가) | 성능 상한 참고치 |
| N2 | **부재 기반 z-score**: 집·노드·서브캐리어별 empty 캘리브 구간의 μ,σ로 표준화 | ✓ | 사용자 원안 |
| N3 | **로그진폭 + 부재 기준 차감**: log|H| − log|H|_empty ≈ 채널 대비 비율 | ✓ | AGC가 곱셈성 → 로그에서 덧셈 제거, 20배 스케일 차이에 물리적으로 대응 |
| N4 | 시간 차분 |H|(t)−|H|(t−1) (또는 로그 차분) | ✓ | AGC는 느리고 행동은 빠름 (README 권장) |
| N5 | 노드 간 비율 rx_i/rx_j | ✓ | 공통 오프셋 상쇄 (README 권장) |
| N6 | 윈도우 내 자체 표준화 (per-window instance norm) | ✓ | 캘리브레이션 자체가 불필요한 대안 |
| Nx | 위 조합 (예: N3 후 N4, N2+N6 등) | ✓ | 조합 시너지 확인 |

### 파생 특징 후보 (ablation)
- 위상: 윈도우 내 위상 변화량/노드 내 서브캐리어 간 위상차(위상 자체는 노이즈 많음 — 변화량 위주).
- 스펙트럼: 서브캐리어 대역 평균 후 STFT(도플러 유사), 모션 에너지(진폭 분산의 시간 프로파일).
- RSSI 채널 추가 여부.

## 6. 모델 후보 (단순 → 복잡 순서로, 항상 단순 모델을 기준선으로 유지)

1. **고전 ML**: 윈도우 통계 특징(서브캐리어 대역별 시간 std/에너지/스펙트럼 요약) →
   Logistic Regression / Random Forest / XGBoost. 빠르므로 **정규화 ablation의 스크리닝 도구**로 사용.
2. **소형 CNN**: (노드×서브캐리어, 시간) 2D 표현 위 소형 conv net. GPU 학습.
3. **시계열 모델**: 1D CNN + GRU 또는 TCN. (트랜스포머는 데이터 규모상 후순위)
4. **도메인 일반화 기법** (시간 남으면): 집을 도메인으로 한 DANN, 집 간 mixup, 노드 드롭아웃 증강.
5. 증강: 시간 이동/크롭, 진폭 스케일 지터(AGC 모사), 서브캐리어 드롭아웃, 가우시안 노이즈.

과적합 경계: 활동 윈도우 약 5~6천 개 + empty 윈도우 다수 — 소형 모델 위주, 파라미터 수 보고.

## 7. 실험 로드맵 (Phase 0 → 7)

각 Phase 완료 시 `results/{NN}_{이름}/`에 PNG + 비교표(CSV/MD) 저장, `RUNLOG.md`에 결론 기록.
**원칙: 뒤 Phase는 앞 Phase의 결론(top 후보)만 가져가서 탐색 공간을 좁힌다.**

| Phase | 내용 | 산출물 |
|---|---|---|
| **P0** | 무결성 확인(manifest sha256 스팟체크) → `synced.csv` 전체 → npz 캐시 병렬 빌드 → 기초 통계표 | 캐시, 세션 통계표 |
| **P1** | EDA: 집·노드별 진폭 스케일/포화 시각화, 행동별 시간-서브캐리어 히트맵·스펙트로그램, 낙상 사이클 파형 확인(5~7초 검증), 결측 구조, **empty 32분 내 드리프트 분석**(캘리브 후 시간이 지나도 통계가 유효한가) | PNG 다수 + 관찰 노트 |
| **P2** | 윈도우/라벨 파이프라인 구축 → **정규화 N0~Nx ablation** (고정: W=200, 고전 ML) — LOHO 3폴드 | 정규화 비교표·막대그래프, top-3 선정 |
| **P3** | 모델 ablation: 고전 ML vs CNN vs CNN+GRU/TCN (top-3 정규화 위에서) | 모델×정규화 매트릭스 표 |
| **P4** | 세부 ablation: 윈도우 길이(100/200/300), 위상/차분/RSSI 특징, 노드 서브셋(4→2개 등), 라벨 정제(이벤트 검출) 유무 | 각 비교표 + 곡선 |
| **P5** | 배포 요소: 캘리브 길이 K(1/5/10/30분), 부재 분위수 기반 자동 임계값, 드리프트 강건성 | 캘리브 길이 곡선, 임계값 규칙 평가 |
| **P6** | 최종 구성으로 **dual-unseen 12조합** 전체 평가 + recall–FA/h 곡선 + 실패 사례 분석(어느 집/인물/행동이 어려운가) | 최종 성능표, 곡선, 오류 분석 |
| **P7** | 최종 리포트(한국어) + 최종 모델 재학습(3집 전체) 및 저장 + `realtime_inference.py`(새 집 배포 시뮬레이션 데모 포함) | `report/FINAL_REPORT.md`, `models/`, 추론 스크립트 |

시간 배분 가이드(유동적): P0~P1 초반 2~3시간, P2~P4 중반 대부분, P5~P7 마무리.
중간에 더 유망한 갈래(예: 도메인 적대 학습, 이벤트 중심 라벨링)가 보이면 RUNLOG에 사유를 적고 추가 실험.
